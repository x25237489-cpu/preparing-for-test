AI Model & Never-Exposed API Key Architecture

How Winter Watch Keeps Keys 100% Hidden in Public Repos:
  • Weather & 6-Winter History: Powered by Open-Meteo (Forecast & Historical Archive APIs) — completely open, CORS-enabled, and requires zero API keys.
  • AI Model (Gemini 3 Flash): In this environment, the key is injected strictly at runtime outside source code. For your live public GitHub Pages deployment, point Winter Watch to a free Cloudflare Worker proxy where GEMINI_API_KEY is stored as an encrypted Cloudflare Secret.

Leave blank to use the built-in runtime AI channel. If hosting publicly on GitHub Pages, paste your Cloudflare Worker URL below (zero keys in HTML!).

export default {
  async fetch(request, env) {
    if (request.method === "OPTIONS") {
      return new Response(null, { headers: { "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "Content-Type" } });
    }
    const body = await request.json();
    const res = await fetch(
      `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent?key=${env.GEMINI_API_KEY}`,
      { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body) }
    );
    const data = await res.text();
    return new Response(data, { headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" } });
  }
